## 为什么不用 HTTPS 路线

| | SSH（本方案） | HTTPS + token |
|---|---|---|
| 沙箱内 push | ✅ 直连，无需授权 | ❌ TLS 被拦，每次要申请完整权限 |
| 凭据 | 密钥文件 | 每次输 token 或存 GCM |
| 首次配置 | 已配完 | 还需生成 PAT |

HTTPS 的 GCM（`git-credential-manager`）已装在便携版里，只作为**备胎**：万一哪天你在沙箱外临时 clone 不想配 SSH，再用它。

## 安全铁律

- 私钥（`id_ed25519`）**永远不贴聊天、不进仓库**；`.ssh/` 已在 `.gitignore`。
- 公钥可以随便给（它就是给 GitHub 的）。
- token 类凭据只放 `.env`（不入库），GitHub 用 SSH 后基本不需要 token。
- 撤销办法：删 `C:\Users\mazix\.ssh` 里对应文件 + `setx GIT_SSH ""` 即回原状。
