# 凭据与本地配置：怎么放才安全

## 三条铁律

1. **别把密钥贴在聊天里**。对话会被存进 `C:\Users\mazix\.dsh\sessions\*.json`，等于明文落盘。
2. **别把密钥写进代码**。哪怕只是"临时试一下"，它也会进 git、进备份、进截图。
3. **密钥只认两个来源**：DSH 凭据库（GUI 里配），或 `.env` / 环境变量（项目里用）。

## 放哪里

| 场景 | 正确位置 | 说明 |
|---|---|---|
| 模型 API Key | DSH 设置界面 → 凭据 | 存在 `C:\Users\mazix\.dsh\.credentials.yaml`，由 DSH 管理，别手改 |
| 项目用的第三方 Key | `<项目>/.env` | 配 `.gitignore` 忽略，仓库里只放 `.env.example` |
| 一次性的临时变量 | 当前终端 `$env:XXX` | 不落盘，关掉就没了 |
| 团队共享的非密配置 | `.env.example` / 文档 | 只写空值和说明 |

## 我（agent）会怎么做

- 读密钥：`$env:XXX`，或从 `.env` 解析，**不在输出里回显值**。
- 需要新密钥：我会告诉你要哪个变量名，你自己填进 `.env`，不回贴给我。
- 检查是否误提交：`git log -p -- .env`、`git ls-files | Select-String env`。

## 常用命令（PowerShell）

```powershell
# 读 .env 到当前会话（值不打印）
Get-Content .env | Where-Object { $_ -match '^\s*[^#].*=' } | ForEach-Object {
    $k, $v = $_ -split '=', 2
    Set-Item -Path "env:$($k.Trim())" -Value $v.Trim()
}
"已加载: " + (Get-ChildItem env: | Where-Object Name -in 'DEEPSEEK_API_KEY','GITHUB_TOKEN' | Select-Object -ExpandProperty Name) -join ', '

# 确认 .env 没被跟踪
git ls-files --error-unmatch .env 2>$null; if ($LASTEXITCODE -ne 0) { ".env 未被跟踪 ✓" }
```

## 万一泄露了

1. 立刻去平台吊销该 key，别指望"删掉 commit 就没事"。
2. 换新 key，重新配置。
3. 用 `git filter-repo` 清理历史（需要时叫我做）。
